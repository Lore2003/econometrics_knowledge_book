
# Econometrics & Quantitative Finance Knowledge Book

Interactive 2D/3D lab for studying and visualizing 31 econometric and quantitative finance models: time series (AR, MA, ARIMA, ARFIMA, HAR-RV), volatility (ARCH, GARCH, EGARCH, GJR, GAS), multivariate systems (VAR, VECM, CCC, DCC, BEKK, O-GARCH), state-space models, and risk measures (VaR, ES).


The knowledge book covers 31 models across six areas:

- Basic processes: white noise, random walk, martingale and related concepts
- Conditional mean: AR, MA, ARMA, ARIMA, ARFIMA and HAR-RV
- Conditional volatility: ARCH, GARCH variants and GAS/DCS
- Multivariate systems and volatility: VAR, VECM and multivariate GARCH models
- State-space and filtering: Kalman filter, realized volatility and stochastic volatility
- Tail risk: VaR approaches and Expected Shortfall

For each model, users can inspect equations and explanatory notes, adjust available parameters, change the sample size, and explore model-specific charts. Diagnostics include ACF and PACF views where applicable; some models also support 3D visualizations.

No installation or build step is required. The project is a self-contained HTML file with its styling and JavaScript included.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Browse or search the model catalog, select a model, and adjust its controls to explore the results.
